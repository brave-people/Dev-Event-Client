위험 구역

아래 액션은 별도 API로 즉시 실행됩니다. 폼 저장과 무관.

인증 (verified) PATCH /admin/v1/hosts/{id}/verified — 별도 호출 / 감사 추적

backfill: DevEvent.organizer가 이 주최명과 정확히 일치하는 행사들을 EventHostMeta로 매핑합니다. 되돌릴 수 없으므로 confirm dialog 필요.

3) 컴포넌트 → API 매핑
  • List 페이지 — GET /admin/v1/hosts 한 번. 검색·필터는 클라이언트 측 (현재 API에 page/q 없음).
  • List ⋯ 메뉴 → 삭제 — DELETE /admin/v1/hosts/{id} (기존)
  • Create 제출 — POST /admin/v1/hosts body = EventHostModifyRequestDTO (links/topics 포함)
  • Modify 제출 (확인 버튼) — PUT /admin/v1/hosts/{id} body = EventHostModifyRequestDTO 전체. links/topics 전체 교체
  • verified 토글 — PATCH /admin/v1/hosts/{id}/verified 단독. 즉시 반영 + 감사 로그
  • backfill 버튼 — POST /admin/v1/hosts/{id}/backfill-events 단독. confirm dialog 후 즉시 실행

※ 개별 POST/DELETE /links, /topics 엔드포인트는 사용 안 함 — PUT 일괄 교체 방식 선택.
